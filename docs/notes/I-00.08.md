# I-00.08 測試骨架：單元與整合測試

## 我原本以為

整合測試連上 `make up` 的 `payment_dev` 最快。交易包在一個 transaction 裡、結束就 rollback，也能讓測試互不干擾。

## 先想清楚的問題與答案

1. 問題：單元測試與整合測試怎麼分？
   答案：整合測試檔第一行是 `//go:build integration`。`make test` 與 `make test-unit` 都是 `go test ./...`，編譯器不會把那些檔案編進去，所以不需要 Docker。`make test-integration` 才加 `-tags=integration`。只靠檔名或目錄不夠，`go test ./...` 仍會編譯它們。
   來源：[Build constraints](https://pkg.go.dev/cmd/go#hdr-Build_constraints)

2. 問題：每個測試用獨立資料庫、獨立 schema，還是 transaction rollback？
   答案：一個測試套件起一個 testcontainers 的 `postgres:18.6`。先對名為 `template` 的 database 跑 `merchant` 與 `payment` 的 Atlas migration，每個測試再 `CREATE DATABASE ... TEMPLATE template`。不使用 compose 的 `payment_dev`。不用 transaction rollback：付款的不變量多半是 commit 之後另一個連線看不看得到。Template 讓每個測試不必重跑 Atlas，又拿到已套用 migration 的真實 schema。建立 database 要串行，因為 Postgres 複製 template 時不允許別人同時連著它；測試本體仍 `t.Parallel()`。
   來源：[CREATE DATABASE](https://www.postgresql.org/docs/current/sql-createdatabase.html)、I-00.03 筆記

3. 問題：測試能不能平行跑？
   答案：可以。容器一個套件只起一次。每個測試有自己的 database，平行不會寫到同一組表。若每個測試各起一個容器，時間會花在 Docker 上。
   來源：[testing.T.Parallel](https://pkg.go.dev/testing#T.Parallel)

## 我做了什麼決定，為什麼

- 決定：`internal/platform/clock` 只有 `Now() time.Time` 與系統時間。可 `Set` / `Advance` 的 `FakeClock` 放在 `internal/platform/testutil`。業務程式之後拿 `clock.Clock`，測試才 import fake。
- 決定：整合測試用同一個 `payment-lab-atlas:1.3.0` image 與 `atlas.hcl` 套用 migration，URL 指到 testcontainers 映射出來的 port。Atlas 容器走 `host.docker.internal`，因為 `--network host` 連不到這個隨機 port。
- 決定：`.go-arch-lint.yml` 允許 `platform` 依賴自己的子套件。否則 `testutil` 不能 import `clock`。`platform` 仍然不能依賴業務模組。
- 放棄的選項與理由：每個測試一個 transaction 然後 rollback。鎖與「commit 之後才看得到」的行為測不到。也放棄共用 `payment_dev`，那是手動 demo 的持久資料。

## 測試證明了什麼

- `TestFakeClockAdvanceMovesNowForward`：`Advance(90s)` 之後 `Now()` 正好往前 90 秒。`make test-unit` 不需要 Docker。
- `TestMigratedMerchantSchemaIsEmpty`：migration 之後 `merchant` schema 存在，而且裡面沒有表。

## 還不懂 / 之後要查

- 表變多之後，`CREATE DATABASE ... TEMPLATE` 會不會把未送出的 catalog 變更也複製進去？現在 template 在 migration 結束、連線切斷之後才被複製。

## 用一句話向面試官解釋

單元測試不碰 Docker；整合測試用真的 Postgres，每個測試自己的 database，而且時間從 `clock.Clock` 來，測試可以把時間往前撥。
